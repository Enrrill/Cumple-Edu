# Vercel

## Qué es

Plataforma de alojamiento (hosting) creados por los mismos autores de [Next.js](Next.js.md). Publica sitios web directamente desde un repositorio de GitHub.

## Para qué sirve en este proyecto

- Aloja la galería en el plan gratuito (dominio `.vercel.app`).
- Despliega automáticamente cada vez que se envía un cambio al repositorio.
- Genera una URL de vista previa (`preview`) por cada rama, útil para revisar cambios antes de mezclarlos.
- Ofrece métricas básicas de uso y logs de los despliegues.

## Alternativas

Netlify, Cloudflare Pages y los servidores privados (VPS) con Docker. Para este proyecto no hacen falta: la comparación está en [Guía de despliegue en Vercel](../Documentaci%C3%B3n/Gu%C3%ADa%20de%20despliegue%20en%20Vercel.md).
